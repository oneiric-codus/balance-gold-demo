# Сайт фитнес-клуба Balance Gold Live — демо-макет

Статический сайт: HTML + CSS + JS, без сборки и без сервера.
Всё, что в `[квадратных скобках]`, — заглушки, на сайте они подсвечены золотом.

## Где что менять

Почти все тексты лежат в одном файле — **`js/data.js`**:

| Что | Раздел в `data.js` |
|---|---|
| Адрес, телефон, часы работы, слоган, соцсети | `club` |
| Пункты меню | `nav` |
| Услуги на главной | `services` |
| Тренажёры по группам мышц | `equipment` (список типовой — сверьте с реальным залом) |
| Тренеры (имя, стаж, цена, контакты, направления) | `trainers` |
| Тарифы (карточки) | `prices`, `extras` |
| Сравнительная таблица цен, доп. услуги | `priceTable`, `extraPrices` |
| Директор, история, цифры | `about` |
| Форматы тренировок | `trainings` |
| Расписание групповых | `schedule` |
| Массаж и сауна | `massage`, `sauna` |
| Отзывы | `reviews` |

- Цвета, шрифты, радиусы, отступы и тёмная/светлая тема — переменные в начале `css/app.css` (новая мобильная система).
  `css/styles.css` — базовые стили первой версии (часть классов ещё используется: форма, модальное окно).
- После правки CSS/JS увеличьте номер `?v=5` в ссылках на файлы, чтобы телефоны не показывали старую версию из кэша.
- Логотип — `assets/logo.png`.
- Чтобы кнопки «Позвонить» звонили, заполните `club.phoneHref`, например `"+73420000000"`.
- Тексты политики конфиденциальности — в `privacy.html`.

## Фото

Сейчас вместо фото стоят серые блоки с подписью. Положите фотографии в `assets/` и замените блок
`<div class="photo-ph">…</div>` на `<img src="assets/фото.jpg" alt="Описание">`.

## Форма заявки

Проверка полей уже работает. Отправка — заглушка: функция `sendLead` в `js/main.js`.
Её можно подключить к Telegram-боту (через небольшой серверный обработчик, чтобы не светить токен бота)
или к сервису форм (Formspree, Getform, Яндекс Формы).

## Как запустить локально

Нужен Python:

```bash
python -m http.server 5173
```

Потом откройте http://localhost:5173

## Как выложить в интернет

Подойдёт любой статический хостинг: залейте все файлы папки как есть.
Например: Reg.ru или Timeweb (обычный хостинг, загрузка по FTP), Netlify, Vercel или GitHub Pages.
